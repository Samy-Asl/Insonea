# INsonea

Vitrine d’INsonea, un projet qui permet de suivre les variations du bruit ambiant depuis le navigateur.

- [Ouvrir la vitrine](https://samy-asl.github.io/Insonea/)
- [Ouvrir l’application](https://samy-asl.github.io/Insonea-APP/)
- [Code de l’application](https://github.com/Samy-Asl/Insonea-APP)

La vitrine tient dans `index.html`. Ouvre ce fichier dans ton navigateur pour la prévisualiser. Le bouton **Ouvrir l’app** mène à l’application, où se font la mesure et le bilan.
